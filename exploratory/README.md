# Exploratory work

This directory contains non-production notebooks and one-off scripts used during data inspection, drafting and manuscript revision.

- Scripts are retained for provenance.
- They are not part of the submission pipeline and should not be used to regenerate manuscript results.
- Some contain hard-coded paths, experimental assumptions or obsolete numbering.
- Production analysis scripts live in `scripts/`; the importable package lives in `sparta/`.

The manuscript-facing parameter sensitivity figures are generated by `scripts/is_figures/figS1_parameter_heatmaps.py`; exploratory scripts in this directory with similar names are historical only.
