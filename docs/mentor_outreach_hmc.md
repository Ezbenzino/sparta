## 联系策略

**顺序建议**：吴燕萍（可及性最高，先练手并拿到本部引荐）→ 周龙岗（匹配
最高）→ 许秋然（产出最高）→ 其余并行。不必等前一个拒绝再发下一个，但
**同一单位避免同日群发**。

**邮件三件套附件**（呼应对导师沟通的既定习惯）：
1. **一页纸摘要 PDF**——左栏：问题+两个算子各一张示意图；右栏：19 切片/
   7 患者/两代平台的四个关键数字 + 一句转化含义；
2. **Fig 1 框架图**（`results/figures/fig1_framework.png`）；
3. 代码仓库链接（**待 git 首次提交后补**——这是目前唯一卡着的硬前置）。

**话术三个要点**：
1. 开门见山说清"这是已完成的工作"：数据、方法、结果、目标期刊均已就绪，
   合作的形式是指导/署名/投稿把关，而不是"请带我开题"——老师的响应成本
   低一个数量级；
2. 主动给出对方能补的位：湿实验验证设计（许/黄/徐）、空间数据的生物学
   解读（周/李/常）、统计与信息学把关（吴/李凯）；
3. 署名问题第一封邮件不谈细节，见面/回复后再坦诚讨论（原则：实质贡献
   对应作者位次，避免"挂名"性质的安排）。

**红线（自查）**：
- 所有邮箱发送前逐个核对现职；
- 不承诺版面费承担方式之前先说明目标期刊（CBC 订阅路线零费用这一点可
  作为"发表成本已解决"写进邮件，很加分）；
- 若对方要求改动方向/加实验，回到 submission_plan 的范围红线判断。
