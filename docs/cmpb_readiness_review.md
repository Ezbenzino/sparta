# CMPB 投稿前完成度评估（2026-10-04）

## 总体判断

当前项目已经可以整理成**方法论文初稿**，研究问题和 CMPB 的计算方法/生物医学应用定位相符；但目前还不能诚实称为“科学验证充分、提交后只等排版”的终稿。眼下最大短板不是排版，而是模型参数与真实组织传输之间仍没有独立的生物学标定。

### 当前新增的发布阻断项

本地 `CITATION.cff` 将 Zenodo DOI 标注为“建库后替换为真实 URL”，因此稿件原来写入的 `10.5281/zenodo.23086431` 尚不能当作已核实的分析归档。本次 CMPB 稿已改成待填 DOI。公开 GitHub 仓库可以访问，但线上 README 的已锁定结果/结论仍是旧版本，未与本地稿件、分析脚本和图件同步。投稿前需要冻结当前源代码、配置和逐切片结果，发布带版本号的仓库/归档，并以可解析 DOI 替换稿内占位文字；否则复现与数据可用性声明不闭环。

## 投稿前必须闭环的事项

1. **确认模型定义和生物学术语。** 抗体字段使用 `CD274`、`PDCD1LG2`（PD-L1/PD-L2 配体）作为一个未标定吸收代理，不能称为抗 PD-1 药物特异性模型。稿件已经按此降调。还需由作者确认“有效网孔 ξ”与 IgG Stokes 半径 r 的几何定义一致（半径、直径或等效通行尺度）；公式当前直接比较 r 与 ξ，这一点容易被审稿人追问。

2. **把 rank-based mesh law 作为模型假设呈现。** `ξ₀=20 nm`、`β=3` 与片内秩分数共同决定约 0.430 的排阻阈值，故 60–65% 零电导边比例及默认 β 下约 97.5% 的方差归因不能作为组织测量或生物学机制比例。稿件与新图已显式说明；主文不应再将其用作核心生物学发现。

3. **补独立功能验证，或继续严格限制主张。** 目前没有抗体实测浓度/渗透数据、细胞跨屏障实验、空间蛋白测量或组织学网孔测量。外部臂只有 3 张切片，其中两张是同一患者相邻乳腺癌切片，另一张是非肿瘤淋巴结；它是跨数据集的模型复现，不是独立患者级或功能验证。若要增强科学层级，这是最有价值的下一步。

4. **按患者而非切片补推断。** 主队列 19 张切片来自 7 位患者，黑色素瘤仅 1 位患者；当前 p 值是每张切片的空间检验，不能回答患者总体差异。建议优先补独立患者队列并做患者聚类/层级分析。若暂时无法新增数据，正文保持描述性并避免“跨患者普遍规律”表述。

5. **扩展空间空模型校准。** 500 次图谱相位符号随机化给出每片 p 值，但它保留图谱功率并不等于完整保留所有空间统计量；现有假阳性率校准据项目记录主要来自单片图，未覆盖全部图结构。建议增加多患者、多平台的空数据校准，或把“14/19 q<0.05”明确写成当前 surrogate 下的结果，而非普适显著性保证。

6. **缺失基因分数必须可见。** 4 张主队列切片没有可用的两基因 Ag_target score，代码用中性值填充；另有 1 张 efflux 缺失。稿件已披露，但任何依赖 target absorption 的分析都应按可用分数做敏感性分析，并将填充切片从相关结果中剔除复核。

7. **确认 external sink 的组织学合理性。** 乳腺外部数据用上皮标记定义模型恶性区，尚未由病理图像确认；淋巴结不是肿瘤。外部 S2 和任何外部切片级最小割结果都只能作为探索性展示。

8. **报告图断裂对字段的影响。** 8/19 主队列切片有 source/sink 节点落在最大连通分量之外；逐点字段对不可达节点使用有限替代值。投稿前最好在补充表列明每片受影响节点数及敏感性复核，而不只报告分量比例。

9. **比较基线需要限缩或加固。** 当前 domain/runtime 对照是固定参数、实现特定的 benchmark，不能证明优于成熟工具。稿件已把它写成描述性/实施背景。若以计算方法创新为主要卖点，最好补充实现成熟的竞争方法、相同预处理与资源条件，并避免将这个对照写成算法性能优越性。

10. **复现发布闭环。** 当前远程 GitHub README 与本地结果版本不一致，`CITATION.cff` 中的 Zenodo URL 也仍是待建库替换的占位。投稿前需在干净环境重跑关键输出，核对代码、配置、结果 JSON 与图脚本，发布带版本号的 release/归档并填入真实 DOI；同时记录 Python 与依赖版本。外部 500 次谱分解耗时较长，可先核对锁定产物与生成脚本，不必在编辑稿生成过程中重算。

## 行政与期刊表单

- 核对作者姓名拼写、单位英文全称、通讯邮箱和 CRediT 贡献；当前稿沿用项目中的 Yize Li / Hangzhou Medical College 信息。
- 确认 ethics statement 是否符合单位对公开、去标识数据二次分析的规定。
- 检查利益冲突、基金声明、数据可用性、未一稿多投及作者最终批准声明。
- Elsevier 现行政策要求对生成式 AI 的实质性写作协助作声明；稿件已加草案声明，作者需核对工具名称、范围并决定是否保留。程序生成的统计图和示意图也需确保作者检查每张图及其图注。
- CMPB 的外审、修回和排期无法保证在某个截止日期前见刊；即使选择订阅路线免 APC，仍不能据此推断出版时间。

## 最优先的三件补强

若资源只够做三项，建议顺序为：**（1）独立患者+直接抗体/屏障功能测量；（2）修复或排除 target signature 缺失后重新做主关联与外部分析；（3）多图结构的 spatial-null 校准并以患者为统计单位复核。** 这三项比继续增加更多仅由同一套模型参数派生的敏感性图更能提高稿件说服力。
