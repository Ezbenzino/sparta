# Legacy archive

This directory contains obsolete scripts retained only for historical traceability. They must not be run as part of the current SPARTA pipeline.

Included material:

- old CMPB manuscript build and figure scripts;
- the retired Node-based DOCX generator;
- analyses that predate the corrected primary melanoma patient mapping and the 2026 extension cohort.

Current production code is in `scripts/` and `sparta/`. Current cohort corrections are documented in `docs/melanoma_mapping_correction.md` and the main README.
